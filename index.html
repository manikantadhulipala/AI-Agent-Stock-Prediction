Overview

This project implements an automated stock trading system that generates and optimizes strategies using Deep Q-Networks (DQN) and Genetic Algorithms (GA). It includes a backtesting engine, interpretability features, a Streamlit-based UI, and export/reporting functionality.

My Contribution: I worked on machine learning strategy development, data preprocessing, integration into the backtesting engine, interpretability modules, visualization/UI, export features, error handling, and testing.
